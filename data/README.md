# Data

This folder contains documentation and, where permitted, datasets used in the analysis.

## Study period

1991–2023

## Variables

- cocoa_yield — Cocoa yield (kg/ha)
- temperature — Mean annual temperature (°C)
- rainfall — Annual precipitation (mm)
- fertilizer — Fertilizer consumption (kg/ha)
- ag_land — Agricultural land (% of land area)

## Sources

- Cocoa yield: FAOSTAT
- Temperature: NASA POWER
- Rainfall: CHIRPS / NASA POWER
- Fertilizer: World Bank
- Agricultural land: World Bank
